Course Description

Study network architecture, switching, protocols, routing, congestion control, and wireless services, then apply prediction, resource allocation, and automation methods to wired, wireless, and edge networks. AI-RAN and ISAC are optional application areas. Official catalog description →

The projects build from measurement to prediction, decision-making, and automation. Students first explain network behavior, then learn to forecast demand and allocate resources. The final project brings these methods to a chosen networking problem, connecting model or agent behavior to measurable system outcomes.

How the Class Works

Eight short lectures of 35–45 minutes, two per project, introduce the core concepts. Class time also includes programming, student-led discussions, project feedback, and demonstrations. Read the project notes and attempt the prelab before starting each project; bring code, results, or questions to studio meetings.

Each studio has a focused task, such as comparing approaches, diagnosing an unexpected result, or choosing the next experiment. Students work with the project code and discuss evidence from plots, traces, and implementation choices, with feedback from peers and the instructor.

Learning Outcomes

By the end of the course, students should be able to:

  1. Explain how protocols, routing, queues, and resource constraints affect network performance.
  2. Design reproducible experiments using throughput, delay, loss, and fairness measurements.
  3. Train predictive models and evaluate them on unseen network conditions.
  4. Compare rule-based, optimization-based, and learned control policies.
  5. Build a network application or agent and explain its benefits and limitations.

Project 4 includes the final demonstration and report; there is no separate written final exam. Prelabs, progress checks, and in-class activities are part of these four assignments. Collaboration rules, late policy, and deadlines will be confirmed before classes begin.

Assessment emphasizes networking understanding, correct implementation, controlled comparisons, and clear interpretation. Explain design choices, document reproducible experiments, and investigate failures. Model complexity or performance gains alone do not determine the grade; well-supported negative results can also demonstrate strong understanding.

Preparation

Familiarity with Python and basic probability is helpful. Prelabs introduce project-specific tools, with more guidance in the early assignments and greater choice in the final project.
