This project studies cellular protocol security through systematic analysis of standards, protocol models, and real implementations. The goal is to identify security gaps in cellular procedures and validate whether deployed 4G/5G systems handle adversarial protocol states, malformed behavior, and unexpected transitions safely.

Research Topics

  • Specification and model based analysis: extracting security-relevant assumptions from cellular standards and using protocol models to reason about authentication, registration, mobility, and access control.
  • Stateful implementation testing: testing real cellular components across protocol states to expose inconsistent handling of edge cases, invalid transitions, and adversarial message sequences.

Course Project Example

Fake Base Station is a course project example under this broader research direction. It explores rogue cellular infrastructure, base-station impersonation, and practical detection workflows for understanding cellular access security threats.
