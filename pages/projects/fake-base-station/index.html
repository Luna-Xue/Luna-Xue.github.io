This project investigates 5G access security threats caused by rogue base stations, unauthorized cellular infrastructure, and suspicious radio access behavior. The goal is to develop physical-layer, protocol-aware, and AI-assisted techniques for identifying untrusted network access points and improving the security of cellular connectivity.

Research Focus

  • Rogue base station detection and attack characterization in 5G networks
  • Physical-layer signal fingerprints for cellular trust assessment
  • Cross-layer defense mechanisms for secure wireless access
  • AI-assisted detection under dynamic and adversarial wireless environments
