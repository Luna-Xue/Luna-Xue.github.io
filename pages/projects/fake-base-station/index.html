This project investigates security threats from fake base stations and unauthorized cellular infrastructure. The goal is to develop physical-layer and cross-layer techniques for detecting suspicious base station behavior and improving wireless access security.

Research Focus

  • Fake base station detection and attack characterization
  • Physical-layer signal fingerprints for cellular trust assessment
  • Cross-layer defense mechanisms for secure wireless access
  • AI-assisted detection under dynamic wireless environments
