This project explores how wireless devices can establish trust using physical-layer signals. Instead of relying only on higher-layer credentials, the work investigates signal-level features, wireless channel properties, and collaborative sensing to support secure device authentication and trust bootstrapping.

Research Focus

  • Physical-layer device authentication
  • Signal-level trust evidence from wireless channels
  • Collaborative signal modification attack analysis
  • Secure bootstrapping for distributed wireless devices

Related Publication

Publication: Secure Device Trust Bootstrapping Against Collaborative Signal Modification Attacks, IEEE INFOCOM, 2023.
