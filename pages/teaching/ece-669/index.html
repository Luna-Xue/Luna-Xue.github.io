Terms Taught

  • 2026 Spring

Course Overview

This course covers security principles and techniques for wireless and mobile systems, with emphasis on wireless network security, mobile system threats, and emerging security challenges in next-generation wireless networks.

Topics

  • Wireless and mobile network fundamentals
  • Authentication, access control, and secure communication
  • Cellular and Wi-Fi security
  • Physical-layer and cross-layer wireless security
  • Security and privacy in AI-enabled wireless systems
