← ECE 668 course page

Four projects. One reproducible learning environment. Study network behavior, train a predictor, learn an allocation policy, and build a diagnostic agent using original ECE 668 teaching materials and a shared Python package.

v0.1.0 · Instructor review edition. The core projects run locally with Python 3.9+ and no additional packages, GPU, API subscription, or radio hardware. Data is synthetic; AI-RAN and OpenISAC-Edge are optional extensions.

Studio-based teaching: eight core short lectures of 35–45 minutes, two per project. Other class meetings center on programming, student-led discussion, project feedback, and demonstrations. Each project handout supports preparation before class.

The project library

ProjectInvestigateIncluded
1 · Paths, Queues, and DelayWhen does the shorter path lose?Finite queues, path policies, buffer configurations, packet traces, and plots.
2 · Predicting Network DemandDoes a predictor survive changing traffic?Episode-based datasets, CPU training, saved models, and shift evaluation.
3 · Learning Resource AllocationHow do throughput and deadlines compete?A resettable environment, rule baselines, Q-learning, and paired comparisons.
4 · Training a Diagnostic AgentCan learned tool use handle multiple faults?A tool sandbox, demonstrations, a trained decision-tree agent, and trajectory evaluation.

Start locally

Extract the download, open a terminal in the package folder, and run:

python3 -m unittest discover -s tests -v
python3 -m ece668.project1
python3 -m ece668.project2
python3 -m ece668.project3
python3 -m ece668.project4

Results appear in runs/p1 through runs/p4. Each guide includes concept notes, a prelab, implementation tasks, output definitions, and a proposed rubric. Edit student/policies.py and add --student to compare your method with the baselines.

From baseline to research question

The supplied methods establish a starting point. Students develop a focused change, test it under controlled conditions, and explain where it succeeds or fails. Project 4 includes the final demonstration and report; alternative network intelligence topics can use the same proposal and evaluation structure.

The agent in this edition learns a compact tool-selection policy. Language-model fine-tuning, live RAN control, and real-data collection require additional project-specific work.
